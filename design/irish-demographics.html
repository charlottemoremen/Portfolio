Exploring Irish Population Demographics

Interactive data dashboard · Vega-Lite

View the live dashboard

“Exploring ROI Population Demographics“ is an interactive dashboard built in Vega-Lite using a CSO high-value dataset. It focuses on regional population change between 2023 and 2024, age distribution, and sex ratios, with linked views that allow users to explore how trends vary across NUTS3 regions. This project was competitively selected to be presented to the CSO in January 2026, and I was later invited to give a guest lecture on the project and data dashboard design to MSc Information Systems students at University College Dublin.
